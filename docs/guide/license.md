# 许可证与署名

`uni-tree-view` 使用 [MIT License](https://github.com/OFreshman/uni-tree-view/blob/main/LICENSE)，允许使用、修改、分发和商业使用。

## 必须保留的内容

再分发项目源码、修改版本、构建产物或软件的主要部分时，必须保留：

- `Copyright (c) 2025-present OFreshman`；
- MIT License 全文。

版权和许可信息可以放在发布包的 `LICENSE`、`NOTICE`、`THIRD-PARTY-NOTICES` 或“开源许可”页面中。MIT 不要求在应用界面、登录页或宣传材料中展示作者名。

## 改造项目的推荐署名

对外发布改造版本时，建议在 README 或第三方许可清单中说明来源，并清楚区分原项目与改造内容：

```text
本项目基于 uni-tree-view 改造。
Copyright (c) 2025-present OFreshman
原项目使用 MIT License：https://github.com/OFreshman/uni-tree-view/blob/main/LICENSE
```

改造版本可以增加新的版权声明，但不得删除原项目的版权和许可信息，也不应暗示原作者为改造版本提供背书。
